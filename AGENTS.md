# scarlett-node agent guidance

This repo is an independent Go node; never import the private app or modify the local gateway repository. Keep the `node-v1` wire schema and fixtures aligned with the Go structs and tests. Treat lease content as untrusted; the gateway origin and key must only come from local configuration. Never invent token usage, weaken deadline/fence protections, log secrets, or retry ambiguous result submissions without a coordinator idempotency contract. `go test ./...` and `go build ./...` must pass. The coordinator service and provider subscription authorization are separate dependencies, not implied by a successful local test.
